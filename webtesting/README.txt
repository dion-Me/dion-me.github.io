KAPALKU STATIC WEBSITE
=======================

Files:
- home.html
- why-us.html
- product.html
- about-us.html
- style.css
- script.js
- assets/img1.png ... img12.png

How to use:
1. Keep all HTML files, style.css, script.js and the assets folder in the same project folder.
2. Open home.html directly in a browser, or use VS Code Live Server.
3. Replace the placeholder PNG files in assets/ with the real photos using the same filenames.
4. The CSS uses fixed aspect-ratio + object-fit: cover so replacing photos with different dimensions will not make the layout unexpectedly huge.
5. Change the company name, WhatsApp number, email, text and product information in the HTML.
6. This is a static frontend prototype. A real admin dashboard/CRUD can be connected later to a backend + database.
